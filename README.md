🚀 About the Project

QUANTEM LAUNCHER is a next-generation Minecraft Java Edition launcher being developed specifically for Android devices.

Our goal is to bring a powerful, lightweight, customizable, and premium Minecraft Java experience to mobile users through modern technology and thoughtful engineering.

Combining Rust and Kotlin, QUANTEM aims to deliver an integrated launcher experience with game management, account options, content discovery, performance configuration, and advanced customization.

One Launcher. Three Account Options. Endless Possibilities.

✨ Planned Features

🎮 Minecraft Management

- Minecraft Java Edition version management.
- Game installation and launching.
- Version profiles and configurations.
- Game file verification and repair.
- Compatible Java runtime management.

👤 Premium Account Center

Three account options:

1. Minecraft Account – Official Microsoft authentication.
2. Ely.by Account – Supported Ely.by authentication and profile integration.
3. Local Account – Offline local profiles with custom usernames.

🎨 Skin Center

- Browse and search Minecraft skins.
- Preview and download skins.
- Save and manage favorite skins.
- Apply supported skins.

🧩 Mod Center

- Discover and manage Minecraft mods.
- Fabric, Forge, NeoForge, and Quilt support targets.
- Automatic mod installation.
- Dependency and compatibility checks.
- Enable, disable, update, and remove mods.

📦 Resource Pack Center

- Browse and download resource packs.
- Automatic installation.
- Preview and manage installed packs.
- Enable, disable, and organize packs.

🌈 Shader Center

- Discover supported shader packs.
- Download and install shaders.
- Renderer compatibility checks.
- Shader configuration and management.

⚙️ Performance Center

- Device capability detection.
- Graphics configuration profiles.
- Memory management.
- Rendering optimization.
- FPS and frame-time diagnostics where supported.
- Low-end device optimization targets.

📱 Platform & Performance Goals

- Target platform: Android.
- Primary architecture target: ARM64.
- Device range: Low-end to flagship.
- Lightweight launcher interface.
- Efficient memory and resource management.
- 30+ FPS target on selected low-end test configurations.

Actual Minecraft performance will depend on hardware, Java runtime, renderer, game version, graphics settings, and thermal conditions.
